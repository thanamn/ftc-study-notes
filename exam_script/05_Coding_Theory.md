# Part 5 — FTC05 Coding Theory (เรียงตามสไลด์)

สคริปต์ส่วนนี้เรียงตามลำดับสไลด์ของบท FTC05 ซึ่งเป็นบทที่ยาวที่สุด ทุกหัวข้อมี `[สไลด์ N]` กำกับ

## ทบทวน checkpointing และภาพรวมบท [สไลด์ 1–4]

สไลด์แรกเป็นการบ้านทบทวนจากบทที่แล้วที่ให้หา consistent cut จากไทม์ไลน์สี่ process และตัดสินว่า recovery line เป็น consistent, strongly consistent หรือ inconsistent สไลด์ที่สี่บอกว่า coding theory คือการศึกษาคุณสมบัติของ code และความเหมาะสมกับงานหนึ่ง ๆ โดยครอบคลุม data compression, error correction, cryptography และ network coding

## ตำแหน่งของ coding theory ในระบบสื่อสาร [สไลด์ 5–8]

สไลด์ที่ห้าเป็นแผนภาพที่ทำให้เห็นตำแหน่งของ coding theory ชัดเจนครับ ฝั่งผู้ส่งมีลำดับคือ Digital Source ไป Source Encoder ไป Encryption ไป Channel Encode ไป Modulator และฝั่งผู้รับย้อนกลับกันคือ Demodulator ไป Channel Decode ไป Decryption ไป Source Decoder ไป Digital Source สิ่งที่ควรสังเกตคือทฤษฎีที่อยู่ตรงกลางแต่ละคู่ Information Theory อยู่ระหว่าง source encoder กับ source decoder, Cryptography อยู่ระหว่าง encryption กับ decryption และ Coding Theory อยู่ระหว่าง channel encode กับ channel decode และมี Noise เข้ามาที่ Channel นี่คือภาพที่บอกว่าการเข้ารหัสช่องสัญญาณเป็นเรื่องคนละเรื่องกับการเข้ารหัสเพื่อความปลอดภัย

สไลด์ที่หกถึงแปดอธิบายว่าสื่อจริงมี noise เสมอ เช่น fiber-optic line, satellite link และ hard disk เราจึงสนใจสองอย่างคือความยาวของ code string และความน่าจะเป็นของ error และแยกแยะว่าการเข้ารหัสเพื่อป้องกัน noise นั้นต่างจาก cryptography ที่ป้องกันศัตรู และต่างจาก steganography ที่ซ่อนข้อมูล

## แนวคิดพื้นฐานและนิยามของ code [สไลด์ 9–10]

สไลด์ที่เก้าให้กรอบของ error correcting framework ครับ message source ส่งค่า W เข้า Encoding ได้ codeword ผ่าน channel ที่มี noise แล้วได้ codeword ที่ผิดเป็น W' จากนั้น Decoding จะพยายามกู้ W กลับมา สไลด์ยกตัวอย่างที่เห็นภาพมากคือข้อความ YES หรือ NO ถูก encode เป็น 00000 หรือ 11111 ถ้าส่ง 00000 แล้วมี noise เปลี่ยนเป็น 01001 ตัว Decoding ก็ยังสามารถกู้กลับเป็น 00000 ได้

สไลด์นี้ยังให้นิยามพื้นฐานที่ต้องจำครับ code C บน alphabet Sigma คือ subset ของ Sigma-star, code แบบ q-nary คือ code บน alphabet ที่มี q สัญลักษณ์ และ binary code คือ code บน alphabet ของศูนย์กับหนึ่ง และให้ตัวอย่าง code สามแบบที่เราใช้ตลอดบทคือ C1 เท่ากับ 00, 01, 10, 11, C2 เท่ากับ 000, 010, 101, 100 และ C3 เท่ากับ 00000, 01101, 10111, 11011 สังเกตว่า C2 นั้นต่างจากที่เคยเห็นเล็กน้อย แต่มันยังเป็น code ที่มีระยะต่ำสุดเท่ากับสอง

สไลด์ที่สิบอธิบายการส่งผ่านช่องสัญญาณว่าเป้าหมายคือ encode เร็ว ส่งง่าย decode เร็ว แก้ error ได้น่าเชื่อถือ และรับข้อมูลได้มากที่สุดต่อหน่วยเวลา และบอกหลักการสำคัญที่สุดว่า วิธีพื้นฐานที่สุดในการต่อสู้กับ error คือ redundancy ตัวอย่างคือเข้ารหัส 0 เป็น 00000 และ 1 เป็น 11111

## ทฤษฎีบทของ Shannon และช่องสัญญาณ [สไลด์ 11–17]

สไลด์ที่สิบเอ็ดรู้จัก Claude Shannon บิดาแห่งทฤษฎีสารสนเทศ สไลด์ที่สิบสองให้ทฤษฎีบท noisy-channel ที่บอกว่า ถ้า rate R น้อยกว่า channel capacity C เราส่งได้เกือบไม่มี error แต่ถ้า R มากกว่า C การทำ error ให้เล็กตามอำเภอใจเป็นไปไม่ได้ โดย C เท่ากับ B log ฐานสองของ (หนึ่งบวก S/N) สไลด์ที่สิบสามอธิบาย channel capacity เพิ่มเติมว่าเป็นอัตราสูงสุดที่ทำได้ด้วย error probability ที่เล็กตามอำเภอใจ และเน้นว่านี่เป็นข้อความเชิง asymptotic คือต้องใช้ข้อความยาว

สไลด์ที่สิบสี่และสิบห้าให้ binary symmetric channel และสูตรความจุ สำหรับ BSC ที่พลิกบิตด้วยความน่าจะเป็น p ความน่าจะเป็นที่ผิด t บิตคือ binomial term และความจุของช่องคือ C ของ p เท่ากับหนึ่งลบ H ของ p โดย H คือ binary entropy function สไลด์ที่สิบหกและสิบเจ็ดยกตัวอย่างว่า การใช้ repetition code ต้องยาวประมาณหกสิบสามเท่าเพื่อให้ error เป็นสิบยกกำลังลบสิบห้า แต่ Shannon บอกว่าสองเท่าก็พอ และสไลด์ที่สิบเจ็ดให้ตัวอย่างการ encode 0 เป็น 000 และ 1 เป็น 111 พร้อมความน่าจะเป็นของข้อผิดพลาดสาม p กำลังสอง ลบ สอง p กำลังสาม

## เรื่องเล่าเส้นทางหลบศัตรู และรหัสสามแบบ [สไลด์ 18–19]

สไลด์ที่สิบแปดและสิบเก้าเป็นเรื่องเล่าที่ดีมากครับ Alice กับ Bob มีแผนที่ตารางเหมือนกัน มีเพียง Alice ที่รู้เส้นทางปลอดภัย เธอต้องส่งลำดับการเดินเป็น NNWNNWWSSWWNNNNWWN ให้ Bob สไลด์แสดงการ encode สามแบบ แบบแรก C1 ใช้คำสองบิตซึ่งทำให้ข้อความยาวและ error ใด ๆ ก็หายนะ แบบที่สอง C2 ใช้คำสามบิตที่ตรวจจับ error เดียวได้ และแบบที่สาม C3 ใช้คำห้าบิตที่แก้ error เดียวได้ นี่คือการสาธิตว่าข้อมูลเดียวกันเลือก code ได้หลายแบบตามพลังที่ต้องการ

## Hamming weight, distance และกฎ detect/correct [สไลด์ 20–24]

สไลด์ที่ยี่สิบให้ Hamming weight ซึ่งคือจำนวนสมาชิกที่ไม่เป็นศูนย์ สไลด์ที่ยี่สิบเอ็ดรู้จัก Richard Hamming สไลด์ที่ยี่สิบสองให้ตัวอย่าง Hamming weight เช่น w(00000) เท่ากับศูนย์, w(11111) เท่ากับห้า, w(1022001) เท่ากับสี่ และ w(1011001) เท่ากับสี่

สไลด์ที่ยี่สิบสามให้ Hamming distance ซึ่งคือจำนวนตำแหน่งที่สองคำต่างกัน ตัวอย่าง h(10101, 01100) เท่ากับสาม และ h(fourth, eighth) เท่ากับสี่ มีสมบัติสามข้อคือเป็นศูนย์เมื่อเท่ากัน สมมาตร และ triangle inequality และให้ minimum distance คือค่าต่ำสุดของระยะห่างระหว่าง codeword ที่ต่างกันทุกคู่ สองกฎที่ต้องจำแบบไม่ต้องคิดคือ code ตรวจจับได้ถึง s error ถ้า h(C) มากกว่าหรือเท่ากับ s บวกหนึ่ง และแก้ได้ถึง t error ถ้า h(C) มากกว่าหรือเท่ากับสอง t บวกหนึ่ง

สไลด์ที่ยี่สิบสี่เปรียบเทียบ Hamming กับ Shannon เป็นตาราง Hamming เน้นตัว codeword และ code ที่ชัดแจ้ง มี trade-off ระหว่าง rate กับ distance และใช้ worst case error ส่วน Shannon จัดการฟังก์ชัน encode และ decode โดยตรง ไม่ชัดแจ้ง มี trade-off ระหว่าง rate กับ error และใช้ stochastic error

## Parity หลายมิติและสัญกรณ์ [สไลด์ 25–30]

สไลด์ที่ยี่สิบห้าและยี่สิบหกสาธิตพลังของ parity bit ครับ การเพิ่ม parity bit หนึ่งบิตทำให้ single error ถูกตรวจจับได้ และสไลด์ยกตัวอย่าง two-dimensional parity code ที่จัดข้อมูลเป็นตารางสองมิติแล้วเติม parity ให้ทุกแถวและทุกคอลัมน์ ซึ่งช่วยให้ตรวจจับและระบุตำแหน่ง error ได้ดีขึ้น

สไลด์ที่ยี่สิบเจ็ดนิยาม (n, M, d)-code โดย n คือความยาว M คือจำนวน codeword และ d คือ minimum distance พร้อมตัวอย่าง C1 เป็น (2,4,1), C2 เป็น (3,4,2) และ C3 เป็น (5,4,3) สไลด์ที่ยี่สิบแปดนิยาม A_q(n,d) ว่าเป็น M ที่มากที่สุดที่เป็นไปได้ และให้กรณีขอบว่า A_q(n,1) เท่ากับ q ยกกำลัง n และ A_q(n,n) เท่ากับ q พร้อมตัวอย่าง A2(8,2) เท่ากับ A2(7,1) เท่ากับสองยกกำลังเจ็ด สไลด์ที่ยี่สิบเก้าให้กฎต่อรหัสว่า ถ้า d เป็นคี่ A2(n,d) เท่ากับ A2(n+1, d+1) และถ้า d เป็นคู่ A2(n,d) เท่ากับ A2(n-1, d-1) และสไลด์ที่สามสิบให้นิยาม equivalence ของสอง code

## Linear และ cyclic code [สไลด์ 31–36]

สไลด์ที่สามสิบเอ็ดนิยาม binary linear code ว่าคือเซตของ binary n-tuple ที่ผลบวกแบบ modulo-2 ของสอง codeword ใด ๆ ยังอยู่ใน code สไลด์ที่สามสิบสองนิยาม cyclic code ว่าต้องเป็น linear และ cyclic shift ใด ๆ ของ codeword ยังเป็น codeword พร้อมตัวอย่าง ternary code 0000, 1212, 2121 และ binary code 000, 110, 011, 101

สไลด์ที่สามสิบสามถึงสามสิบหกเป็นแบบฝึกหัดสี่ข้อที่ควรฝึกครับ ข้อแรกให้ใช้ nearest neighbor decoding กับ code C เท่ากับ 0000, 1110, 1011 เมื่อรับ 0110 ข้อที่สองถามความน่าจะเป็นที่รับ 100010 เมื่อส่ง 000000 บน BSC ที่ p เท่ากับ 0.01 ข้อที่สามให้หา minimum distance ของ code 00000, 01110, 10011, 11111 และข้อที่สี่ให้บอกว่า code 00000000, 11111000, 01010111, 10101111 ตรวจจับและแก้ได้กี่ error

## ทฤษฎีของ cyclic code และ generator polynomial [สไลด์ 37–41]

สไลด์ที่สามสิบเจ็ดอธิบายว่า k คือจำนวนบิตข้อมูลและ n คือความยาวที่เข้ารหัส โดยได้ codeword จากการคูณข้อมูลด้วยตัวคูณที่ยาว n ลบ k บวกหนึ่ง บิต ซึ่งบิตของตัวคูณคือสัมประสิทธิ์ของ generator polynomial ตัวอย่างคือตัวคูณ 11001 ให้ g(x) เท่ากับ 1 บวก x กำลังสาม บวก x กำลังสี่

สไลด์ที่สามสิบแปดและสามสิบเก้าอธิบายว่าการเลื่อน cyclic ใด ๆ ยังเป็น codeword, ข้อมูล k บิตแทนพหุนามดีกรี k ลบหนึ่ง และรหัส (n,k) cyclic มี generator polynomial ดีกรี r เท่ากับ n ลบ k และต้องเป็นตัวหารของ x กำลัง n ลบหนึ่ง พร้อมกันนี้ code ตรวจจับ single error และ burst error ที่สั้นกว่า n ลบ k

สไลด์ที่สี่สิบเป็นตารางการแยกตัวประกอบของ x กำลัง n บวกหนึ่ง สำหรับ n ตั้งแต่หนึ่งถึงสามสิบเอ็ด ซึ่งมีประโยชน์มากครับ ตัวอย่างที่ต้องจำคือ n เท่ากับเจ็ด ได้ (x บวกหนึ่ง)(x กำลังสาม บวก x บวกหนึ่ง)(x กำลังสาม บวก x กำลังสอง บวกหนึ่ง), n เท่ากับห้า ได้ (x บวกหนึ่ง)(x กำลังสี่ บวก x กำลังสาม บวก x กำลังสอง บวก x บวกหนึ่ง) และ n เท่ากับสิบห้า ซึ่งมี factor หลายตัวรวมถึง x กำลังสี่ บวก x บวกหนึ่ง

สไลด์ที่สี่สิบเอ็ดสาธิตการคูณแบบ modulo-2 ด้วยตัวอย่าง 10001100101 คูณ 11001 เท่ากับ 110000100011101 และอธิบายว่าเราสามารถสร้างวงจรด้วย delay element ได้ แต่รหัสนี้ไม่ separable เพราะ data กับ check bit ปนกัน

## การ encode และ decode ด้วยฮาร์ดแวร์ [สไลด์ 42–46]

สไลด์ที่สี่สิบสองให้ตารางการทำงานของวงจร encode ที่มีคอลัมน์ shift clock, input data, O4, i3, O3 O2 O1 และ encoded output ซึ่งแสดงการคำนวณทีละรอบสไลด์ที่สี่สิบสามสาธิตการ decode ด้วยการหารครับ กรณีไม่มี error 110000100011101 หารด้วย 11001 ได้ remainder 00000 แปลว่าไม่ตรวจพบ error แต่กรณีมี single error 110000100111101 ให้ remainder 01011 ซึ่งไม่เป็นศูนย์ แปลว่าตรวจพบ

สไลด์ที่สี่สิบสี่เป็นสไลด์ที่ควรให้ความสนใจครับ มันแสดงว่าเมื่อมี error สามบิตในรูปแบบหนึ่ง 110000111010101 หารด้วย 11001 กลับได้ remainder 00000 นั่นคือ **error ไม่ถูกตรวจพบ** ขณะที่เมื่อ error อยู่ติดกัน 110000011011101 กลับให้ remainder 00110 ซึ่งตรวจพบได้ นี่คือบทเรียนว่า code นี้ไม่ใช่ omnipotent และต้องระวังรูปแบบ error ที่ทำให้หารลงตัวพอดี

สไลด์ที่สี่สิบห้าและสี่สิบหกอธิบายการสร้าง encoder และ divider circuit ด้วย shift register ที่ทำการคูณและหารผ่าน feedback loop และย้ำว่าถ้าไม่มี error เราจะได้ remainder เป็นศูนย์

## ตัวอย่างการ encode/decode จริง และ code rate [สไลด์ 47–54]

สไลด์ที่สี่สิบเจ็ดให้ generator polynomial สำหรับ n เท่ากับห้าคือ (x บวกหนึ่ง) และสำหรับ n เท่ากับเจ็ดคือ (x กำลังสาม บวก x บวกหนึ่ง) สไลด์ที่สี่สิบแปดถึงสี่สิบเก้าสาธิต encoding และ decoding ตัวอย่างที่หนึ่งด้วย g(x) เท่ากับ (1 บวก x)

สไลด์ที่ห้าสิบเอ็ดถึงห้าสิบสามเป็นตัวอย่างที่สองซึ่งตรงกับ HW05 ครับ สำหรับ g(x) เท่ากับ 1 บวก x บวก x กำลังสาม ข้อมูล 0111 encode ได้ 0100011 และการ decode คำที่ไม่มี error 0100011 ให้ K กลับมา ขณะที่คำที่มี error 0101011 ให้ผลลัพธ์ผิดไป สังเกตว่าตัวอย่างนี้ช่วยให้เห็นการทำงานจริงของ shift register ผ่านตารางค่าของ D1, D2, D3, A1 และ A3

สไลด์ที่ห้าสิบสี่นิยาม code rate ว่าเท่ากับ log ฐาน q ของ M หารด้วย n ซึ่งเป็นสัดส่วนของ bandwidth ที่ใช้ส่งข้อมูลจริง

## Error detection และเกณฑ์การประเมิน [สไลด์ 55–58]

สไลด์ที่ห้าสิบห้าและห้าสิบหกอธิบาย error detection ผ่าน Venn diagram ที่มี data space และ code space โดย error space กับ noncodeword อยู่ด้านนอก และย้ำว่า error detection เป็นเป้าหมายที่เจียมตัวกว่าการแก้ error และเหมาะเมื่อช่องดีพอที่จะส่งซ้ำได้ สไลด์ที่ห้าสิบเจ็ดให้เกณฑ์การประเมิน detecting code ห้าด้าน ได้แก่ redundancy, encoding complexity, decoding complexity โดย separable code ถอดรหัสฟรี, capability ซึ่งมีกฎว่าตรวจ d-bit error ต้องมีระยะ d บวกหนึ่ง และ closure ซึ่งคือทำเลขคณิตบน codeword ได้ตรง ๆ สไลด์ที่ห้าสิบแปดเป็นเรื่องอ่านเพิ่มเติมที่บอกว่าอยู่นอกขอบเขต และสไลด์ที่ห้าสิบเก้าเป็นการบ้าน HW05 ที่ให้ generate (7,4) cyclic code จากข้อมูล 0101, 1001, 0010, 1110, 0000 พร้อม hardware implementation

## Home exercise cyclic code [สไลด์ 60–63]

สไลด์ที่หกสิบถึงหกสิบสามเป็นเฉลยการบ้าน cyclic code ครับ ซึ่งแสดงการ encode แบบ systematic ด้วยการหารยาว สำหรับข้อมูล 0101 ค่าที่ได้คือ 0100111 ซึ่งเป็น codeword แบบ separable ที่ขึ้นต้นด้วยข้อมูลเดิม สไลด์ที่หกสิบเอ็ดและหกสิบสามแสดงตารางการทำงานของวงจรสำหรับ g(x) เท่ากับ 1 บวก x กำลังสอง บวก x กำลังสาม พร้อมค่าของ A0, A2, A3 และ D1 ถึง D3

## Error control codes และ overlapped parity [สไลด์ 64–73]

สไลด์ที่หกสิบสี่แสดง error control สำหรับระบบดิจิทัลที่มี corrector และ checker ล้อม functional unit สไลด์ที่หกสิบห้าให้ error model ได้แก่ symmetric และ asymmetric, single และ multiple, unidirectional ซึ่งเปลี่ยนได้ทั้งสองทิศแต่ไม่พร้อมกัน และ byte error สไลด์ที่หกสิบหกจำแนก error correcting code กับ error detecting code และสไลด์ที่หกสิบเจ็ดแสดง functional block ที่มี memory, ฟังก์ชัน f, compare และ corrector

สไลด์ที่หกสิบแปดเป็นหัวใจของ overlapped parity ครับ มันเป็น Single Error Correcting code ที่ใช้ data แปดบิตกับ check สี่บิต และให้เงื่อนไขว่า 2 กำลัง k ลบหนึ่ง มากกว่าหรือเท่ากับ m บวก k โดย m คือ data bits และ k คือ parity bits การจัดวางบิตมี 12 ตำแหน่ง โดยตำแหน่งที่เป็นกำลังสองคือ 1, 2, 4 และ 8 เป็น check bit C1 ถึง C4 และตำแหน่งอื่นเป็น data bit D1 ถึง D8

สไลด์ที่เจ็ดสิบให้สูตรคำนวณ check bit ที่ต้องจำครับ C1 เท่ากับ D1 XOR D2 XOR D4 XOR D5 XOR D7, C2 เท่ากับ D1 XOR D3 XOR D4 XOR D6 XOR D7, C3 เท่ากับ D2 XOR D3 XOR D4 XOR D8 และ C4 เท่ากับ D5 XOR D6 XOR D7 XOR D8 สไลด์ที่เจ็ดสิบเอ็ดให้ตัวอย่างที่ data 11100001 กับ check 1110 และสไลด์ที่เจ็ดสิบสองให้ผลว่า syndrome 1100 ชี้ว่า D8 ผิด นี่คือตัวอย่างที่สมบูรณ์ของการอ่าน syndrome ที่เราพูดถึงในเวอร์ชันก่อนหน้า

## BCH, checksum และ constant-weight [สไลด์ 74–78]

สไลด์ที่เจ็ดสิบสี่แนะนำ BCH code ซึ่งเป็น cyclic error-correcting code ที่ใช้พหุนามบน finite field และแก้ multiple bit error ได้ ใช้ในดาวเทียม เครื่องเล่น CD และ DVD เป็นต้น สไลด์ที่เจ็ดสิบห้าถึงเจ็ดสิบเจ็ดอธิบาย checksum code สี่แบบคือ single precision, double precision, residue และ Honeywell พร้อมตัวอย่างการคำนวณที่ 10101001 บวก 00111001 ได้ 11100010 แล้ว checksum คือ complement 00011101 และสไลด์ที่เจ็ดสิบแปดอธิบาย constant-weight code ที่ทุก codeword มีจำนวนหนึ่งเท่ากัน ตรวจจับ unidirectional error ได้ทั้งหมด

## Arithmetic weight, residue และ dual rail [สไลด์ 79–90]

สไลด์ที่เจ็ดสิบเก้าอธิบาย arithmetic weight error ว่าเป็นจำนวนน้อยสุดของ signed power of two ที่ต้องบวกเข้าไปเพื่อเปลี่ยนค่าถูกเป็นค่าผิด พร้อมตัวอย่างที่แสดงว่า single carry error ทำให้เกิด bit error ได้หลายบิต สไลด์ที่แปดสิบจำแนก arithmetic code เป็น AN code และ residue code สไลด์ที่แปดสิบเอ็ดแสดงว่า residue code รักษา code หลังการดำเนินการ สไลด์ที่แปดสิบสองและแปดสิบสามอธิบาย low-cost residue code ที่ใช้ A เท่ากับสองยกกำลัง a ลบหนึ่ง และคำนวณ mod ได้ด้วยการบวกส่วนย่อยด้วย end-around carry โดยไม่ต้องหาร พร้อมตัวอย่าง mod 15

สไลด์ที่แปดสิบสี่ให้สูตรเลขคณิตบน residue-coded operand คือการบวกและลบทำแยกส่วน data กับ check และการคูณก็ทำแยกได้ แต่การหารและ square root ยาก สไลด์ที่แปดสิบห้าถึงแปดสิบเจ็ดอธิบาย unordered code, m-of-n code และ Berger code ซึ่ง Berger นั้นนับจำนวนหนึ่งใน data แล้วต่อด้วย complement สไลด์ที่แปดสิบแปดให้ตัวอย่าง Berger code ที่ k เท่ากับหกและ c เท่ากับสาม สไลด์ที่แปดสิบเก้าและเก้าสิบอธิบาย dual rail code ที่ encode 1 บิตเป็นคู่ 01 หรือ 10 และแสดงตัวอย่างฟังก์ชัน F เท่ากับ a-bar b บวก b c-bar บวก ac กับ dual ของมัน

## การประยุกต์ [สไลด์ 91–92]

สไลด์ที่เก้าสิบเอ็ดแสดงการตรวจจับ error ใน UPC-A ด้วย checksum โดย weight vector คือ 3,1,3,1 ไปเรื่อย ๆ และ A เท่ากับสิบ พร้อมตัวอย่างการคำนวณ check digit ของรหัส 03600029145 ได้ 2 และอธิบายว่าบาร์โค้ดใช้ 7 บิตต่อหนึ่งหลัก สไลด์ที่เก้าสิบสองอธิบาย JPEG Huffman coding ที่บีบอัดได้ยี่สิบถึงเก้าสิบเปอร์เซ็นต์ พร้อมภาพเปรียบเทียบระหว่างภาพต้นฉบับ ภาพที่ error ใน Huffman table และภาพที่แก้แล้ว


## จากคำบรรยายในห้อง [insights]

**หัวใจของ error correction คือการระบุตำแหน่ง** อาจารย์ย้ำหลายครั้งว่า สิ่งที่สำคัญที่สุดของการแก้ error คือความสามารถในการ **locate ว่า error อยู่ที่บิตไหน** เพราะถ้าเรารู้ตำแหน่ง เราก็แค่กลับบิตนั้น (1 กลายเป็น 0 หรือ 0 กลายเป็น 1) ดังนั้นคำว่า error control จึงครอบคลุมทั้ง detect, locate และ correct โดยเรียงตามลำดับนี้

**โครงสร้างของชั้นการสื่อสาร** อาจารย์อธิบายว่า modulator ทำหน้าที่เป็นตัว encode คือแปลง digital เป็น analog เพื่อส่งผ่าน channel ที่มี noise ส่วน demodulator ทำหน้าที่เป็นตัว decode นี่เป็นเหตุผลว่าทำไม coding กับ modulation จึงเชื่อมกัน และสรุปว่า **recompute แล้ว compare** เป็นแกนของการตรวจทั้งใน cyclic code, ECC, checksum และ residue

**สูตร detect/correct ในรูปที่อาจารย์พูด** คือ detect ได้ถึง d ลบหนึ่ง และ correct ได้ถึง (d ลบหนึ่ง) หารสองปัดลง ซึ่งเป็นรูปเดียวกับ d มากกว่าหรือเท่ากับ s บวกหนึ่ง และ d มากกว่าหรือเท่ากับสอง t บวกหนึ่ง แต่เขียนจากมุมของ d ที่รู้อยู่แล้ว ซึ่งอ่านง่ายกว่าเวลาตอบโจทย์ว่า "โค้ดนี้แก้ได้กี่บิต"

**ที่มาของ parity code** อาจารย์ชี้ว่า ถ้าเลือก generator polynomial เป็น **x บวกหนึ่ง** จะได้ parity code พอดี นี่คือคำตอบว่าทำไม parity ถึงมองเป็น code ได้ และย้ำว่า generator ต้องเป็น **ตัวประกอบของ x ยกกำลัง n บวกหนึ่ง**

**โจทย์ท้ายคาบที่บอกว่าเป็นแนวข้อสอบ/การบ้าน** คือ ให้สร้าง **cyclic code ขนาด (7,4)** โดยหา generator ที่เหมาะสม สร้าง hardware implementation ของ encoder แล้วป้อน data เข้าไปตรวจว่าตรงกับที่คำนวณ และลอง **ใส่ error หนึ่งบิต** แล้ว decode เพื่อดูว่า remainder ไม่เป็นศูนย์ ซึ่งยืนยันว่าฮาร์ดแวร์ที่สร้างถูก นี่คือเหตุผลที่ใน Part นี้ผมเน้นการหารยาวและการอ่าน remainder มากเป็นพิเศษ
